# WU23 Kneeboard · Ан-28 VFR

Кнібордо для VFR-турів на Ан-28 по всіх POI MSFS 2024 World Update 23 (Польща та Балтія). Канал **AeroTruck**.

**Відкрити:** https://rostykk.github.io/wu23-kneeboard/

- 6 польотів: Литва, Латвія, Естонія, Польща 1–3 (по одному на стрім)
- Nav log з вітром (WCA, TH, MH, GS, ETE/ETA), фактичні ATA, паливний план за профілем Ан-28 ATSimulations
- Перемикач lb / kg / gal, ліміт баків, попередження про номінал (≤60 хв)
- Маршрути обходять повітряний простір Росії та Білорусі (Калінінград, Нарва)
